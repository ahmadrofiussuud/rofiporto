# Phase 6 — Organic off-page strategy (Rp0)

24 November 2026. Tidak ada akun/profil eksternal diubah, pesan dikirim, formulir disubmit, atau backlink dibuat otomatis. Tindakan hanya setelah pemilik memilih dan mengizinkan kanalnya. Link tidak dijamin meningkatkan posisi atau langsung mengalahkan GitHub.

## Prinsip

Portfolio menjadi pusat identitas; profil profesional dan sumber kredibel membantu orang menemukan karya dan memeriksa kontribusi. Link keluar ke berita kampus adalah atribusi sumber, **bukan backlink dari kampus ke portfolio**. Backlink baru hanya terjadi jika halaman eksternal benar-benar menaut ke portfolio. Hindari timbal balik wajib, anchor exact-match berulang, profil palsu, paid links, komentar massal, private blog network, submission otomatis dan permintaan penghapusan GitHub yang sah.

## Bahasa dan urutan pencarian

GitHub bukan pesaing yang perlu dirusak; itu profil pemilik sendiri. Bio Inggris pada screenshot dan live HTML GitHub menjelaskan cuplikan Inggris yang terlihat. Rofiporto masih Indonesia. Google dapat mengambil snippet dari isi halaman dan memilihnya menurut query; metadata Rofiporto tidak bisa mengganti isi GitHub/Instagram. Opsi Translate this page bukan tanda seluruh portfolio diterjemahkan.

Penyebab kenaikan GitHub tertentu belum terbukti. Domain, isi, relevansi query dan hubungan link merupakan konteks umum, bukan diagnosis individual dari screenshot. Jangan menjanjikan “tautan bio = ranking 1”. Pantau query nama penuh dan halaman portfolio di GSC; bedakan impressions, clicks, CTR, average position dan perubahan jumlah situs profil yang terlihat. Tidak mengirim pencarian/klik buatan untuk memanipulasi ranking.

## Evaluasi

Catat tanggal tindakan, URL sumber/target, keberadaan link publik, relevansi editorial dan tanggal pemeriksaan. Evaluasi bulanan manual dengan rentang GSC setara setelah perubahan benar-benar deployed; tanpa jadwal otomatis baru. Jumlah backlink mentah bukan sasaran. Bila tidak ada akses analytics/referral, tandai belum tersedia daripada membuat angka.
